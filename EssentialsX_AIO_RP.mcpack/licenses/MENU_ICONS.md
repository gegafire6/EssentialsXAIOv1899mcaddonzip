# Menu icon assets

v1.8.40 replaces the 48 shared menu PNGs and adds eight symbols for admin tools.
Every image is a 64×64 RGBA PNG with transparency, resized from Microsoft's
Fluent Emoji 3D artwork using Lanczos resampling. Forms keep their existing
layout and display sizes; 64×64 is the source texture resolution.

Source: https://github.com/microsoft/fluentui-emoji/tree/1ffb34c752ecf5d402f04cfb4b392c77f57c54bc
License: MIT, included in fluentui-emoji-LICENSE.txt.
Exact source paths, pinned revision and checksums: menu-icon-sources.json.

Main categories, registered member features and registered admin tools use the
custom icons. The shared icons also refresh other forms that already use them.
Vanilla inventory item textures continue to represent their original items.

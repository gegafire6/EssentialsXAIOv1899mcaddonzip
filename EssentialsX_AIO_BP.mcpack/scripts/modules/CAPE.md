# Server cape display

Open **Essentials Menu → My Settings → Cape Display** and switch **Show server cape** on or off. The included cyan server cape is a visual-only wearable with a slight sway; viewers need the resource pack.

The cape uses the chest equipment slot and gives no armor or flight. Remove chest armor, Elytra or cosmetic wings before enabling it. The toggle never replaces or removes those items. A manually removed cape is not recreated automatically; turn the feature on again when the chest slot is empty. The saved setting follows the equipped cape, including after reconnecting, and becomes off when the cape is removed, the Cosmetics module is disabled, or the player enters vanish. This control applies to the add-on's server cape, not Minecraft account capes or capes from other packs.
